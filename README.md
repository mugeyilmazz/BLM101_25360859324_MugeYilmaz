## Proje Konusu
**Python ile Otomatik HTML Sayfası Oluşturucu**

## Proje Açıklaması
Bu proje, Python programlama dili kullanılarak kullanıcıdan alınan bilgilerle
otomatik olarak basit bir HTML web sayfası oluşturan bir uygulamadır.
Program, Python'daki string işlemleri ve dosya yazma (file write) yeteneklerini
kullanarak `index.html` dosyasını üretir.

## Kullanılan Konular
- String işlemleri
- Dosya okuma/yazma
- Döngüler (for)
- Kullanıcıdan veri alma (input)
- HTML ve CSS temelleri

## Programın Çalışma Mantığı
1. Program çalıştırıldığında kullanıcıdan ad, bölüm, alınan dersler ve biyografi bilgileri alınır.
2. Girilen dersler virgül kullanılarak liste haline getirilir.
3. Alınan bilgiler HTML formatına dönüştürülür.
4. `index.html` dosyası oluşturularak bilgiler bu dosyaya yazılır.
5. Oluşturulan dosya tarayıcıda açıldığında basit bir web sayfası görüntülenir.

## Program Nasıl Çalıştırılır?
1. Python yüklü bir bilgisayarda `html_olusturucu.py` dosyası çalıştırılır.
2. Programın sorduğu sorular cevaplanır.
3. Program sonunda `index.html` dosyası otomatik olarak oluşturulur.
